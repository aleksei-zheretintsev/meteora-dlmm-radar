# Справочник показателей

## Метрики ликвидности и активности

| Показатель | Что означает | Важное уточнение |
|---|---|---|
| Market Cap (MC) | Капитализация токена | Не равно TVL пула; в заголовке «было → стало» |
| Total TVL | Общая ликвидность DLMM-пула | Не вся ликвидность активна |
| Active TVL | Активная ликвидность возле текущей цены | Может стать нулевой |
| Fees | Комиссии за используемое 30-минутное окно Meteora | Не прогноз дохода LP |
| Fees / Active TVL | Отношение комиссий к активной ликвидности, % | Нулевой Active TVL требует осторожности |
| Volume / Active TVL | Отношение оборота к активной ликвидности, % | Большой оборот не гарантирует доходность |
| Swaps | Количество сделок | Не число уникальных трейдеров |
| Traders | Количество уникальных трейдеров | Может меняться по периодам |
| Holders | Держатели токена | Не число LP |
| Top 10 | Концентрация у десяти крупных держателей | Зависит от определения источника |
| Total LPs | Поставщики ликвидности конкретного пула | Малое число LP повышает операционный риск |
| Fee / Bin Step | Базовая комиссия / шаг ценовых бинов | У разных DLMM-пулов токена разные значения |
| Bin Rent (SOL) | Оценка затрат на создание отсутствующих bin-array | Не обязательно точная итоговая стоимость |
| Transfer Fee | Комиссия токена на перевод | Не комиссия за обмен в пуле |

## Дополнительная проверка токена

**GMGN**: GMGN Views, GMGN Total Fees, Bundler, Phishing*, DEV, Rug %, Mint Authority и Freeze Authority (если поля доступны). Цветовые пороги — прикладные эвристики, а не аудит контракта.

**InsightX**:

| Показатель | Расчёт | Ограничение |
|---|---|---|
| Bubble MAX | Самая большая доля связанного кластера `clusters[].pct` | Из **InsightX**, не из Bubblemaps |
| Bubble OTHER | `total_cluster_pct − Bubble MAX`, минимум 0 | Только обнаруженные сервисом кластеры |
| Top Wallet | Максимальная доля кандидата после исключения распознанных AMM/DEX/пулов/бирж | Не доказывает независимость; пустой Scanner = `н/д` |
| Honeypot | `honeypot.score` по шкале 0–100, **0 лучше, 100 хуже** | 0 = не найдены проверяемые ограничения, **не гарантия** безопасности |

## Обновления

**Update:** свежий 30-минутный снимок Meteora плюс изменение относительно первоначальной карточки.

**Update 30MIN:** свежий 30-минутный снимок Meteora плюс изменения, рассчитанные самим API Meteora за 30 минут.

**Top Wallet / Honeypot:** независимые от временного окна токеновые показатели с кешем около 120 секунд. Нет данных — `н/д`.

**X:** кнопка ведёт на профиль → сообщество → публикацию → поиск по mint. **Хэштег** в подписи помогает найти несколько пулов одного токена.
