# Roadmap

## Implemented in the current development baseline

Automated discovery and configurable screening; Telegram cards with original/update views; SQLite persistence; GMGN/InsightX enrichment; wallet-cluster indicators; preliminary technical-wallet exclusions; Honeypot display; X/social routing and hashtags; manual Update controls; Windows on-demand launch.

## Ongoing validation / near-term

- Verify social post routing on real tokens and correct provider social metadata.
- Improve Top Wallet accuracy with owner-level / pool-account identification and stale-data handling.
- Improve source-level audit logging and metadata freshness diagnostics.
- Add repeatable regression tests with sanitized fixtures.

## Potential future research (not implemented)

Price action and volatility analytics, range/position recommendations, bin-level liquidity profiling, historical outcomes, KOL/X quality analytics, additional visualization tools. These are ideas, **not existing AI modules or proven forecasts**.
