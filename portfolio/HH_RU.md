# HH.ru — блок для портфолио / резюме

## Название проекта
**Meteora DLMM Radar — автоматизированный мониторинг и аналитика пулов ликвидности Solana**

## Краткое описание (подойдёт для раздела «Обо мне» или описания проекта)

Самостоятельный портфолио-проект на Python: разработал Telegram-бота для автоматического поиска и первичного анализа новых DLMM-пулов Meteora в сети Solana. Интегрировал данные Meteora, GMGN, InsightX и DEX Screener, реализовал фильтры отбора, расчёт показателей ликвидности и риска, визуальные карточки с двумя режимами обновления, хранение истории в SQLite и запуск через ярлык Windows.

**Стек:** Python, REST API, JSON, requests, SQLite, Telegram Bot API, Pillow, GitHub.

**Роль:** самостоятельная разработка, интеграция API, настройка аналитики и тестирование.

**Ссылка:** ВСТАВИТЬ ПОСЛЕ ПУБЛИКАЦИИ ФАКТИЧЕСКИЙ URL GitHub-репозитория Meteora DLMM Radar.

**Позиционирование:** демонстрация навыков Python-автоматизации, API-интеграций и обработки данных для Web3. Не указывать как оплачиваемый коммерческий опыт или полноценный AI-прогнозный движок.

## Как добавить на HH

В прошлом резюме проект AI Real Estate Lead Automation был оформлен отдельным портфолио-материалом, а GitHub — через «Другие способы связи». Для Meteora DLMM Radar после публикации: добавить новую карточку / описание проекта в раздел портфолио, при необходимости вставить действующий URL GitHub в текст описания, а ссылку на профиль GitHub оставить общей в «Других способах связи». Не заменять старый проект — добавить второй.

Если HH принимает только изображения для портфолио, можно использовать отдельную PNG-карточку с названием, 3–4 компетенциями и QR/URL на опубликованный репозиторий.
